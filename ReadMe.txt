Benötigte Pakete können unter requirements.txt gefunden werden.

Mithilfe von main.py kann ein Programmdurchlauf gestartet werden.

WARNUNG: Wie in der Arbeit beschrieben, werden die Entfernungen gecached. 
Dies führt zu einem Speicherbedarf von insgesamt rund 150GB.
Ein kompletter Durchlauf dauerte rund eine Woche auf einem MacBook Pro mit einem M2Pro Prozessor.
